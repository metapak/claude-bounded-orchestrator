# Provenance and attribution

Claude Bounded Orchestrator was created by Mehmet Apak as a Claude Code adaptation of the bounded workflow developed in [Codex Bounded Orchestrator](https://github.com/metapak/codex-bounded-orchestrator).

The earlier Codex project was inspired by the public [donvito/codex-astra-luna-orchestrator](https://github.com/donvito/codex-astra-luna-orchestrator) project. This repository preserves Apache-2.0 licensing and attribution. The names of upstream authors and projects are used only to describe provenance; they do not imply endorsement.

This Claude repository implements its own Claude Code project-agent files, settings, opt-in skills, installer, metadata-only ledger, tests, documentation, and release packaging.
