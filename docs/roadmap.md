# Roadmap

Roadmap items are proposals, not compatibility promises.

## 0.2.x

- Gather live smoke-test reports across current Claude Code clients.
- Improve installation diagnostics without weakening conflict preservation.
- Add more metadata-only ledger usability checks.

## Future candidates

- Optional domain expertise packs with the same explicit invocation and no tool grants.
- A machine-readable, privacy-preserving workflow summary for local inspection.
- Documented adapters for teams that already use issue trackers, without requiring an external service.
- Stronger candidate identity helpers that remain standard-library only.

## Later exploration

- Evaluate whether native Claude Code capabilities can replace more instruction-level rules.
- Study interoperable bounded-workflow conventions across coding agents while keeping each repository honest about its own runtime.

Please open a feature request describing the problem and expected user outcome before a large implementation.
