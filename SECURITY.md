# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting

Do not open a public issue containing an exploitable vulnerability, credentials, private prompts, personal data, or proprietary source. Use GitHub's private vulnerability reporting feature for this repository when available. If private reporting is unavailable, open a public issue asking the maintainer to enable a private contact channel without disclosing sensitive details.

## Boundary

This project configures Claude Code agents and local helper tools. It is not a sandbox. Shell access, user-approved permissions, local hooks, MCP servers, and the host operating system remain part of the security boundary. Review installer previews and backups, use least privilege, and run untrusted work in an isolated environment.
